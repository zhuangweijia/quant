## 1. 模块概述

看板模块是用户登录后的首页，聚合展示账户核心数据、持仓分布、策略表现、最近交易和系统告警。用户通过看板可快速了解当前账户状态，无需进入子页面即可掌握全局。

## 3. 功能清单

### 3.1 统计卡片

| 编号 | 功能 | 数据来源 | 刷新方式 |
|------|------|----------|----------|
| D-01 | 总资产展示（现金 + 持仓市值） | 交易模块 positions + 账户余额 | WebSocket 实时 |
| D-02 | 日盈亏金额 + 百分比 | 当日已实现盈亏 + 浮动盈亏 | WebSocket 实时 |
| D-03 | 总盈亏金额 + 百分比 | 累计历史盈亏 | 页面加载时 |
| D-04 | 运行策略数 / 上限 | 策略模块 | WebSocket 实时 |
| D-05 | 今日交易次数 | 订单模块（当日 count） | 页面加载时 |
| D-06 | 未读告警数 | 风控模块 alerts | WebSocket 实时 |

**卡片样式规则**：
- 盈利为正：数字显示红色（A股风格）或绿色（可配置）
- 盈利为负：数字显示绿色或红色（与上方相反）
- 数字格式：金额保留 2 位小数，百分比保留 2 位，大数字用万/亿简写

### 3.2 权益曲线

| 编号 | 功能 | 说明 |
|------|------|------|
| D-07 | 权益曲线图 | X 轴时间，Y 轴权益金额 |
| D-08 | 时间范围切换 | 1天 / 1周 / 1月 / 3月 / 1年 / 全部 |
| D-09 | 基准对照线 | 可选显示"初始资金不变"基准线 |
| D-10 | Tooltip 详情 | 鼠标悬停显示：日期、权益值、日收益率 |
| D-11 | 区域缩放 | 支持鼠标框选放大某段时间范围 |
| D-12 | 数据粒度 | 1天以内按小时，1天以上按天，1年以上按周 |

### 3.3 持仓分布

| 编号 | 功能 | 说明 |
|------|------|------|
| D-13 | 饼图展示 | 各持仓标的按市值占比 |
| D-14 | 维度切换 | 按标的 / 按市场 / 按策略 三种维度 |
| D-15 | Tooltip 详情 | 标的名、市值、占比百分比 |
| D-16 | 空状态 | 无持仓时显示空状态占位 |
| D-17 | 点击穿透 | 点击饼图某块跳转到交易页持仓列表 |

### 3.4 策略表现排名

| 编号 | 功能 | 说明 |
|------|------|------|
| D-18 | 排名表格 | 列：排名、策略名、市场、状态、总收益率、夏普比率、最大回撤 |
| D-19 | 排序方式 | 默认按收益率降序，可点击列头切换排序 |
| D-20 | 状态标签 | 运行中(绿) / 已停止(黄) |
| D-21 | 点击跳转 | 点击策略名跳转到策略详情页 |

### 3.5 最近交易

| 编号 | 功能 | 说明 |
|------|------|------|
| D-22 | 交易列表 | 列：时间、标的、方向（买/卖）、成交价、数量、盈亏 |
| D-23 | 数量限制 | 默认展示最近 20 条 |
| D-24 | 盈亏着色 | 盈利红色/亏损绿色（或可配置） |
| D-25 | 查看更多 | 底部"查看全部"按钮跳转到交易页 |

### 3.6 系统告警摘要

| 编号 | 功能 | 说明 |
|------|------|------|
| D-26 | 告警列表 | 最新 5 条未读告警：级别图标、标题、时间 |
| D-27 | 级别样式 | info(蓝) / warning(黄) / error(红) |
| D-28 | 标记已读 | 点击某条告警后标记为已读 |
| D-29 | 查看全部 | 跳转到风控 → 告警记录页 |

## 4. 接口需求

### 后端 API

| 方法 | 路径 | 说明 | 返回数据 |
|------|------|------|----------|
| GET | `/api/v1/dashboard/overview` | 统计卡片数据 | total_equity, cash, position_value, daily_pnl, daily_pnl_pct, total_pnl, total_pnl_pct, running_strategies, total_strategies, today_trades, unread_alerts |
| GET | `/api/v1/dashboard/equity-curve?range=1M` | 权益曲线数据点 | [{date, equity, benchmark}] |
| GET | `/api/v1/dashboard/strategy-ranking` | 策略排名 | [{strategy_id, name, total_return, sharpe_ratio, max_drawdown, trade_count, status}] |

### WebSocket 推送

| 主题 | 触发条件 | 推送数据 |
|------|----------|----------|
| `dashboard:update` | 持仓/订单/策略状态变更时 | 更新的卡片数据字段 |

## 5. 交互细节

### 5.1 页面加载

1. 并行请求 `overview` + `equity-curve` + `strategy-ranking`
2. 显示骨架屏/skeleton loading
3. 数据到齐后渲染
4. 建立 WebSocket 连接，接收实时更新

### 5.2 实时更新

- WebSocket 推送 `dashboard:update` 时，仅更新变化的数据卡片
- 权益曲线不实时更新，通过手动刷新或定时（每 30 秒）拉取
- 策略排名表不实时更新，每次进入页面时重新拉取

### 5.3 错误处理

- 某个接口失败时，对应区域显示错误提示 + 重试按钮
- 不阻塞其他区域的展示
- WebSocket 断连时，页面顶部显示"连接断开"提示条
