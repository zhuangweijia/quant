# 行情模块（Market）需求文档

> 版本：v1.0  
> 日期：2026-05-13  
> 前置模块：用户管理

---

## 1. 模块概述

行情模块提供多市场（A股/美股/加密货币）的实时和历史行情数据查看。用户可搜索标的、查看 K 线图、管理自选列表，行情数据通过 WebSocket 实时推送。

## 3. 功能清单

### 3.1 标的搜索

| 编号 | 功能 | 说明 |
|------|------|------|
| M-01 | 关键词搜索 | 输入股票代码或名称，实时联想匹配 |
| M-02 | 市场筛选 | Tab 切换 A股/美股/加密货币 |
| M-03 | 搜索结果列表 | 展示：代码、名称、市场、最新价、涨跌幅 |
| M-04 | 点击查看详情 | 点击搜索结果中的标的，打开下方 K 线图 |
| M-05 | 加入自选 | 搜索结果中每行有「加自选」按钮 |

**搜索规则**：
- 最少输入 1 个字符触发搜索
- 搜索请求 debounce 300ms
- 结果最多展示 50 条
- A 股支持拼音首字母搜索（如「gzmt」→ 贵州茅台）

### 3.2 自选列表

| 编号 | 功能 | 说明 |
|------|------|------|
| M-06 | 自选列表展示 | 展示已收藏标的：代码、名称、最新价、涨跌幅 |
| M-07 | 实时更新 | 自选标的的价格通过 WebSocket 实时刷新 |
| M-08 | 添加自选 | 搜索结果或 K 线图页面上点击 ★ 按钮 |
| M-09 | 删除自选 | 自选列表中每行有 ✕ 按钮 |
| M-10 | 拖拽排序 | 自选标的可拖拽调整顺序 |
| M-11 | 持久化 | 自选列表存储到数据库（user_watchlist 表） |
| M-12 | 点击查看 | 点击自选标的打开对应 K 线图 |
| M-13 | 清空自选 | 一键清空所有自选（需二次确认） |

**自选限制**：单用户最多 50 个自选标的。

### 3.3 K 线图

| 编号 | 功能 | 说明 |
|------|------|------|
| M-14 | K 线主图 | OHLCV 蜡烛图，阳线红/阴线绿（可配置） |
| M-15 | 成交量副图 | K 线下方展示成交量柱状图，涨跌颜色与 K 线一致 |
| M-16 | 周期切换 | 1m / 5m / 15m / 30m / 1h / 4h / 1D / 1W |
| M-17 | 数据加载 | 默认加载最近 500 根 K 线 |
| M-18 | 历史回溯 | 鼠标向左滚动时加载更早的 K 线（每次加载 500 根） |
| M-19 | 区域缩放 | 底部 dataZoom 滑块，支持鼠标滚轮缩放 |
| M-20 | Tooltip | 鼠标悬停显示：日期、开/高/低/收、涨跌幅、成交量 |
| M-21 | 十字光标 | 鼠标移动时显示十字线对齐 |

### 3.4 技术指标

| 编号 | 指标 | 类型 | 参数（默认） |
|------|------|------|-------------|
| M-22 | MA（移动均线） | 主图叠加 | MA5(黄), MA10(蓝), MA20(紫), MA60(灰) |
| M-23 | BOLL（布林带） | 主图叠加 | N=20, K=2 |
| M-24 | VOL（成交量） | 副图 | 默认显示 |
| M-25 | MACD | 副图 | 快=12, 慢=26, Signal=9 |
| M-26 | RSI | 副图 | 周期=14 |
| M-27 | KDJ | 副图 | N=9, M1=3, M2=3 |

**指标交互**：
- 指标按钮组在 K 线图上方，可点击切换开关
- 主图指标和副图指标可同时启用多个
- 指标参数可在设置中修改

### 3.5 行情数据采集

| 编号 | 功能 | 说明 |
|------|------|------|
| M-28 | A股日K采集 | 交易日收盘后（15:30）采集完整日 K |
| M-29 | A股分钟K采集 | 交易时段每 5 分钟采集 5m K 线 |
| M-30 | 美股K线采集 | 交易时段每分钟采集 |
| M-31 | 加密货币K线采集 | 7×24 每分钟采集 |
| M-32 | 实时 Tick 推送 | 加密货币通过 WebSocket 实时推送 Tick |
| M-33 | 数据补全 | 检测到缺失数据时自动从数据源补拉 |
| M-34 | 数据源切换 | 主数据源失败时自动切换备用源 |

## 4. 接口需求

### 后端 API

| 方法 | 路径 | 参数 | 说明 |
|------|------|------|------|
| GET | `/api/v1/market/symbols` | keyword, market | 搜索标的 |
| GET | `/api/v1/market/klines` | symbol, market, timeframe, start, end, limit | 获取 K 线数据 |
| GET | `/api/v1/market/watchlist` | - | 获取自选列表 |
| POST | `/api/v1/market/watchlist` | symbol, market | 添加自选 |
| DELETE | `/api/v1/market/watchlist/{id}` | - | 删除自选 |
| PUT | `/api/v1/market/watchlist/sort` | ids[] | 调整排序 |
| GET | `/api/v1/market/quote` | symbols[] | 批量获取最新报价 |

### WebSocket

| 路径 | 订阅方式 | 推送数据 |
|------|----------|----------|
| `/ws/market` | `{action: "subscribe", symbols: ["BTCUSDT","AAPL"]}` | `{type: "tick", data: {symbol, price, volume, change_pct, timestamp}}` |

### user_watchlist

| 字段 | 类型 | 说明 |

## 6. 交互细节

### 6.1 页面加载流程

1. 加载自选列表
2. 默认展示自选列表第一个标的的 K 线（或上次查看的标的）
3. 建立 WebSocket 连接，订阅自选标的的实时 Tick
4. 无自选时显示空状态引导

### 6.2 K 线图加载

1. 默认加载 1D 周期最近 500 根 K 线
2. 切换周期时重新请求
3. 滚动到左边缘时加载更多历史数据
4. 加载中显示 loading 动画

### 6.3 实时更新

- 自选列表中的价格每收到 Tick 时更新
- K 线图当前最右边的 K 线实时更新（价格和成交量）
- 新的 K 线周期开始时自动创建新的一根

## 7. 验收标准

| 编号 | 验收条件 |
|------|----------|
| MA-01 | 搜索联想响应时间 < 500ms |
| MA-02 | A股/美股/加密货币标的都能正常搜索 |
| MA-03 | K 线图加载 < 1s，可缩放、可查看历史 |
| MA-04 | 8 个周期切换正常，数据准确 |
| MA-05 | 至少 3 个技术指标（MA/MACD/RSI）可正常叠加显示 |
| MA-06 | 自选列表增删改排序正常，刷新页面后数据保留 |
| MA-07 | WebSocket 实时价格更新延迟 < 3s |
| MA-08 | 数据源断连时降级提示，不影响其他功能使用 |
| MA-09 | 无自选、无搜索结果时有空状态引导 |
