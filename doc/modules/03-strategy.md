# 策略模块（Strategy）需求文档

> 版本：v1.0  
> 日期：2026-05-13  
> 前置模块：用户管理

---

## 1. 模块概述

策略模块负责策略的完整生命周期管理，包括创建、编辑、启动、停止、删除。用户使用 Python 编写策略代码（继承 BaseStrategy 基类），配置参数后即可启动运行或提交回测。

---

## 2. 页面列表

| 页面 | 路径 | 说明 |
|------|------|------|
| 策略列表 | `/strategy` | 展示所有策略，支持筛选、搜索、快捷操作 |
| 创建策略 | `/strategy/create` | 编写策略代码 + 配置参数 |
| 编辑策略 | `/strategy/:id/edit` | 编辑已有策略（需先停止） |
| 策略日志 | `/strategy/:id/logs` | 查看策略运行日志 |

### 3.2 功能清单

| 编号 | 功能 | 说明 |
|------|------|------|
| S-01 | 策略列表展示 | 表格展示用户所有未删除的策略 |
| S-02 | 状态筛选 | 下拉筛选：全部 / 草稿 / 运行中 / 已停止 |
| S-03 | 市场筛选 | 下拉筛选：全部 / A股 / 美股 / 加密货币 |
| S-04 | 关键词搜索 | 按策略名称模糊搜索 |
| S-05 | 分页 | 默认每页 20 条，支持切换 10/20/50 |
| S-06 | 创建策略 | 点击「创建策略」按钮跳转创建页 |
| S-07 | 编辑策略 | 点击「编辑」跳转编辑页（运行中策略需先停止） |
| S-08 | 启动策略 | 点击「启动」→ 状态变为运行中 |
| S-09 | 停止策略 | 点击「停止」→ 二次确认 → 状态变为已停止 |
| S-10 | 删除策略 | 点击「删除」→ 二次确认 → 软删除 |
| S-11 | 查看日志 | 点击策略名称或「日志」按钮跳转日志页 |
| S-12 | 状态标签颜色 | 草稿(info灰) / 运行中(success绿) / 已停止(warning黄) |
| S-13 | 空状态 | 无策略时显示引导创建的空状态 |

**操作权限**：
- 草稿策略：可编辑、启动、删除
- 运行中策略：可停止、查看日志
- 已停止策略：可编辑、启动、删除

### 4.2 功能清单

| 编号 | 功能 | 说明 |
|------|------|------|
| S-14 | 策略名称输入 | 2-128 字符 |
| S-15 | 目标市场选择 | A股 / 美股 / 加密货币 |
| S-16 | 策略描述 | 可选，最多 1000 字符 |
| S-17 | 代码编辑器 | Monaco Editor，Python 语法高亮、自动补全 |
| S-18 | 代码验证 | AST 语法检查 + import 白名单检查 + BaseStrategy 继承检查 |
| S-19 | 验证结果反馈 | 验证成功显示绿色提示，失败显示红色错误信息和行号 |
| S-20 | 参数编辑 | JSON 格式编辑器，带格式校验 |
| S-21 | 保存草稿 | 保存策略，状态为「草稿」 |
| S-22 | 保存并回测 | 保存后直接跳转到回测页面并预填参数 |
| S-23 | 编辑模式 | 编辑已有策略时预填所有字段 |
| S-24 | 代码模板 | 新建策略时预填 BaseStrategy 模板代码 |
| S-25 | 策略示例库 | 提供 3-5 个示例策略可供选择作为模板 |

### 4.3 代码验证规则

| 检查项 | 规则 |
|--------|------|
| 语法检查 | Python AST 可正常解析 |
| import 白名单 | pandas, numpy, talib, math, datetime, collections, itertools, functools, typing, dataclasses, enum, decimal |
| 禁止 import | os, sys, subprocess, socket, requests, open, eval, exec, __import__ |
| 继承检查 | 代码中必须存在继承自 BaseStrategy 的类 |
| 抽象方法 | 继承类必须实现 `on_init` 和 `on_bar` |
| 代码大小 | 不超过 100KB |

## 6. 接口需求

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/strategies` | 策略列表（支持筛选/搜索/分页） |
| POST | `/api/v1/strategies` | 创建策略 |
| GET | `/api/v1/strategies/{id}` | 策略详情 |
| PUT | `/api/v1/strategies/{id}` | 更新策略 |
| DELETE | `/api/v1/strategies/{id}` | 软删除策略 |
| POST | `/api/v1/strategies/{id}/start` | 启动策略 |
| POST | `/api/v1/strategies/{id}/stop` | 停止策略 |
| POST | `/api/v1/strategies/validate` | 验证策略代码 |
| GET | `/api/v1/strategies/{id}/logs` | 策略日志（支持筛选/分页） |
| GET | `/api/v1/strategies/templates` | 获取示例策略模板列表 |
| GET | `/api/v1/strategies/templates/{name}` | 获取指定模板代码 |

## 7. 业务规则

| 规则 | 说明 |
|------|------|
| 策略上限 | 每用户最多 50 个策略（含已删除） |
| 运行上限 | 每用户最多同时运行 10 个策略 |
| 运行中不可编辑 | 必须先停止再编辑 |
| 运行中不可删除 | 必须先停止再删除 |
| 草稿不可日志 | 草稿状态没有日志可查看 |
| 首次启动验证 | 启动前自动执行代码验证 |
| 启动失败回滚 | 启动失败时状态回滚为已停止 |

## 8. 验收标准

| 编号 | 验收条件 |
|------|----------|
| ST-01 | 策略 CRUD 全流程正常 |
| ST-02 | 代码编辑器有语法高亮，预填模板代码 |
| ST-03 | 代码验证能检测语法错误、禁止 import、缺失继承 |
| ST-04 | 运行中策略无法编辑和删除，有明确提示 |
| ST-05 | 启动/停止操作正常，状态标签实时更新 |
| ST-06 | 策略日志实时追加，级别筛选和搜索正常 |
| ST-07 | 策略数量和运行数达到上限时有提示 |
| ST-08 | 编辑页保存后跳转列表，新策略出现在列表顶部 |
