# 回测模块（Backtest）需求文档

> 版本：v1.0  
> 日期：2026-05-13  
> 前置模块：用户管理、策略、行情

---

## 1. 模块概述

回测模块允许用户使用历史行情数据验证策略表现。用户选择策略、配置参数和时间范围后，系统异步执行回测，生成包含收益曲线、统计指标、交易明细的完整报告，并支持多策略对比分析。

---

## 2. 页面列表

| 页面 | 路径 | 说明 |
|------|------|------|
| 回测中心 | `/backtest` | 新建回测 + 历史回测列表 |
| 回测报告 | `/backtest/result/:id` | 单个回测的详细报告 |
| 回测对比 | `/backtest/compare` | 多个回测结果对比 |

| 编号 | 功能 | 说明 |

| B-05 | 时间范围 | 起始日期 ~ 结束日期，日期选择器 |

| B-10 | 表单校验 | 时间范围、资金、标的等字段实时校验 |
| B-11 | 开始回测 | 校验通过后异步执行，页面显示进度 |
| B-12 | 回测进度 | 进度条 + 百分比 + 已处理 bar 数 / 总 bar 数 |
| B-13 | 进度推送 | 通过 WebSocket 实时推送进度 |

| B-15 | 历史列表 | 展示所有回测记录，按时间倒序 |
| B-16 | 状态标签 | 运行中(info) / 已完成(success) / 失败(danger) |
| B-17 | 查看详情 | 跳转回测报告页 |
| B-18 | 多选对比 | 勾选 2-5 个结果进行对比 |
| B-19 | 删除结果 | 删除单个回测结果 |

### 4.3 统计指标完整列表

| 指标 | 计算方式 |
|------|----------|
| 总收益率 | (期末权益 - 初始资金) / 初始资金 × 100% |
| 年化收益率 | (1 + 总收益率)^(252/交易日数) - 1 |
| 夏普比率 | (日均收益 - 无风险利率) / 日收益标准差 × √252 |
| 索提诺比率 | (日均收益 - 无风险利率) / 下行标准差 × √252 |
| 最大回撤 | 峰值到谷底的最大跌幅 |
| 最大回撤持续期 | 从回撤开始到恢复前高的天数 |
| Calmar 比率 | 年化收益率 / 最大回撤 |
| 胜率 | 盈利交易数 / 总交易数 × 100% |
| 盈亏比 | 平均盈利 / 平均亏损的绝对值 |
| 总交易次数 | 完整的开仓→平仓次数 |
| 日均交易次数 | 总交易次数 / 回测交易日数 |
| 平均持仓周期 | 所有交易持仓时间的平均值 |
| 利润因子 | 总盈利 / 总亏损的绝对值 |

## 6. 撮合规则

| 订单类型 | 成交规则 |
|----------|----------|
| 市价单 | 以下一根 K 线的开盘价 ± 滑点成交 |
| 限价买单 | K 线最低价 ≤ 限价时，以限价成交 |
| 限价卖单 | K 线最高价 ≥ 限价时，以限价成交 |
| 止损卖单 | K 线触及止损价时，以止损价 ± 滑点成交 |
| 成交量限制 | 单笔成交量 ≤ 该 K 线成交量的 25% |

### 手续费模型

| 市场 | 买入 | 卖出 |
|------|------|------|
| A股 | 0.025% 佣金 + 0.01% 过户费 | 买入费用 + 0.1% 印花税 |
| 美股 | 每股 $0.005（最低 $1） | 同买入 |
| 加密货币 | 0.1% (Maker) / 0.1% (Taker) | 同买入 |

## 7. 接口需求

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/v1/backtest/run` | 提交回测任务 |
| GET | `/api/v1/backtest/results` | 回测结果列表 |
| GET | `/api/v1/backtest/results/{id}` | 回测结果详情（含曲线和交易明细） |
| DELETE | `/api/v1/backtest/results/{id}` | 删除回测结果 |
| POST | `/api/v1/backtest/compare` | 获取对比数据 |
| GET | `/api/v1/backtest/{id}/export` | 导出交易明细 CSV |

### WebSocket

| 推送 | 数据 |
|------|------|
| `backtest:progress` | `{task_id, progress, current_bar, total_bars, status}` |

---

## 8. 业务规则

| 规则 | 说明 |
|------|------|
| 并发限制 | 每用户最多同时 3 个回测任务 |
| 超时 | 单个回测最多运行 10 分钟 |
| 时间范围 | 最长 5 年 |
| 数据完整性 | 缺失率 > 10% 时拒绝执行并提示 |
| 结果保留 | 永久保留（可手动删除） |

---

## 9. 验收标准

| 编号 | 验收条件 |
|------|----------|
| BT-01 | 回测表单校验正常，时间/资金/标的限制生效 |
| BT-02 | 回测异步执行，进度条实时更新 |
| BT-03 | 回测完成后报告页 6 个指标卡片数据正确 |
| BT-04 | 权益曲线和回撤曲线正确渲染 |
| BT-05 | 月度收益热力图数据准确，颜色深浅对应幅度 |
| BT-06 | 交易明细表分页正常，可导出 CSV |
| BT-07 | 手续费和滑点计算正确 |
| BT-08 | 对比功能支持 2-5 个结果，指标高亮最优 |
| BT-09 | 回测超时和失败时正确提示 |
| BT-10 | 数据缺失 > 10% 时拒绝执行并提示缺失范围 |
