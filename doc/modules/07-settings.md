# 设置模块（Settings）需求文档

> 版本：v1.0  
> 日期：2026-05-13  
> 前置模块：用户管理

---

## 1. 模块概述

设置模块提供系统级配置管理，包括交易所 API 凭证管理、通知渠道配置、全局交易参数调整、交易模式切换以及用户个人信息管理。所有敏感信息（API Secret、SMTP 密码）使用 AES-256 加密存储，前端显示时脱敏处理。

### 4.2 功能清单

| AKShare | 无需配置 | 开源库，直接调用 |

### 5.3 Webhook 请求格式

```json
{
  "event": "risk:alert",
  "level": "error",
  "title": "止损触发",
  "message": "BTCUSDT 浮亏达 -10.5%，已自动平仓",
  "timestamp": "2026-05-13T10:30:00Z",
  "signature": "sha256=abcdef..."
}
```

签名计算：`HMAC-SHA256(webhook_secret, body_json)`

## 8. 接口需求

### 8.1 交易所配置 API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/settings/brokers` | 获取所有交易所配置（Secret 脱敏） |
| PUT | `/api/v1/settings/brokers/{broker_name}` | 保存交易所配置 |
| POST | `/api/v1/settings/brokers/{broker_name}/test` | 测试交易所连接 |
| GET | `/api/v1/settings/trading-mode` | 获取当前交易模式 |
| PUT | `/api/v1/settings/trading-mode` | 切换交易模式 |

**PUT /api/v1/settings/brokers/{broker_name} 请求体：**

```json
{
  "api_key": "actual_api_key",
  "api_secret": "actual_api_secret",
  "params": {"network": "mainnet"}
}
```

**GET /api/v1/settings/brokers 响应：**

```json
[
  {
    "broker_name": "binance",
    "market": "crypto",
    "api_key": "abcd****efgh",
    "has_secret": true,
    "params": {"network": "mainnet"},
    "connected": true
  },
  {
    "broker_name": "alpaca",
    "market": "us_stock",
    "api_key": "APCK****WXYZ",
    "has_secret": true,
    "params": {"environment": "paper"},
    "connected": false
  }
]
```

**PUT /api/v1/settings/trading-mode 请求体：**

```json
{
  "mode": "live",
  "password": "admin123"
}
```

## 10. 安全要求

| 项目 | 要求 |
|------|------|
| API Secret 存储 | AES-256-GCM 加密，密钥从环境变量 `ENCRYPTION_KEY` 读取 |
| 前端脱敏 | API Key 显示前 4 位 + `****` + 后 4 位 |
| 密码传输 | HTTPS 加密传输，不在 URL 中暴露 |
| 交易模式切换 | 切换到实盘需输入密码验证 |
| 配置查看权限 | 只有本人可查看自己的配置 |
| 敏感字段日志 | API Key/Secret 不写入应用日志 |

## 11. 业务规则

| 规则 | 说明 |
|------|------|
| 模拟盘默认 | 新用户默认模拟盘模式，无需配置交易所 |
| 实盘前提 | 切换到实盘必须至少配置一个交易所 API |
| 策略停止 | 切换交易模式时自动停止所有运行策略 |
| 参数生效 | 系统参数保存后即时生效，无需重启 |
| 配置隔离 | 每个用户的交易所配置和通知配置完全独立 |
| 密码校验 | 新密码至少 8 位，必须包含字母和数字 |
| 当前密码校验 | 修改密码时必须验证当前密码正确性 |
| 测试连接超时 | 交易所测试连接超时 10 秒 |
| 邮件测试 | 测试邮件主题为 "QuantPlatform 通知测试" |
| Webhook 测试 | 发送 `{"event": "test", "timestamp": "..."}` 到配置 URL |

## 13. 错误处理

| 错误码 | HTTP | 场景 | 提示信息 |
|--------|------|------|----------|
| BROKER_TEST_FAILED | 502 | 交易所连接失败 | "交易所连接失败: {detail}" |
| BROKER_TEST_TIMEOUT | 504 | 交易所连接超时 | "交易所连接超时，请检查网络和配置" |
| SMTP_TEST_FAILED | 502 | 邮件发送失败 | "邮件发送失败: {detail}" |
| WEBHOOK_TEST_FAILED | 502 | Webhook 请求失败 | "Webhook 请求失败: HTTP {status}" |
| INVALID_API_KEY | 400 | API Key 格式错误 | "API Key 格式不正确" |
| PASSWORD_MISMATCH | 400 | 当前密码错误 | "当前密码不正确" |
| PASSWORD_TOO_WEAK | 400 | 新密码强度不足 | "密码至少 8 位，需包含字母和数字" |

## 14. 验收标准

| 编号 | 验收条件 |
|------|----------|
| ST-01 | 交易所配置保存成功，API Key 脱敏显示 |
