# Quant Desk 登录页文案更新设计

## 背景

Quant Desk 已从多市场量化交易工作台转型为面向沪深 300 的每日股票分析与推荐平台。当前登录页仍在描述交易执行、低延迟路由和风控能力，与实际产品不符。

## 目标

- 保留 `Quant Desk` 品牌名。
- 用直观易懂、不过度营销的语言说明产品价值。
- 明确股票池、更新频率和分析结果。
- 只更新登录与注册页文案，不改变布局、交互或认证逻辑。

## 文案映射

| 位置 | 新文案 |
| --- | --- |
| 顶部标签 | 每日智能选股 |
| 品牌名 | Quant Desk |
| 左侧介绍 | 每日分析沪深 300，筛出值得关注的股票，并用简单清楚的理由解释每一次推荐。 |
| 信息卡 1 标签 / 内容 | 股票池 / 沪深 300 |
| 信息卡 2 标签 / 内容 | 更新频率 / 每个交易日 |
| 信息卡 3 标签 / 内容 | 分析结果 / 强推 · 观望 · 回避 |
| 登录标题 | 登录 Quant Desk |
| 登录说明 | 查看今日选股结果、股票排名与推荐理由。 |
| 登录按钮 | 查看今日选股 |
| 注册标题 | 创建 Quant Desk 账户 |
| 注册说明 | 创建账户，开始查看每日选股分析。 |
| 注册按钮 | 创建账户 |

移动端品牌栏继续显示 `Quant Desk`。用户名、密码、确认密码、登录/注册切换等通用认证文案保持不变。

## 验收标准

- 页面不再出现多市场交易、交易执行、低延迟路由或风控相关文案。
- 登录态与注册态分别显示上述对应标题、说明和按钮。
- 桌面端三张信息卡完整呈现股票池、更新频率和分析结果。
- 页面现有响应式布局和认证行为不受影响。
